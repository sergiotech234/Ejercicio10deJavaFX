# Selección desde Lista Desplegable en Java

## Descripción

Este proyecto consiste en desarrollar una aplicación en **Java** con una interfaz gráfica que incluye una **lista desplegable (`JComboBox`)** y un botón. Al pulsar el botón, se muestra el elemento seleccionado por el usuario.

El objetivo del ejercicio es practicar el uso de listas desplegables y la captura de datos desde componentes gráficos mediante **Swing**.

## Objetivos

- Crear una lista desplegable.
- Permitir seleccionar elementos.
- Capturar la opción seleccionada.
- Mostrar el valor elegido.
- Practicar el manejo de eventos.

